# Notesy — Support

**Notesy: Calm Note Taking** is a warm, minimal handwriting notes app for iPad.

This repo backs the support site at
**<https://alyakan.github.io/notesy-support/>** (privacy policy:
<https://alyakan.github.io/notesy-support/privacy/>).

## Getting help

- **Found a bug or have a feature idea?** [Open an issue](../../issues) on this
  repository — it goes straight to the developer.
- **Questions about donations/purchases:** donations are optional tips handled
  entirely by Apple. They unlock nothing, and refunds are handled through
  [Apple's report a problem](https://reportaproblem.apple.com) page.

## Tips

- **Tools** live behind the small tab on the edge of the paper — pull it out.
- **Pause mid-stroke** to snap it into a straight line (can be turned off in
  Settings).
- **Turn pages** by swiping with two fingers (one finger when
  "Draw with finger" is off).
- **Build your own paper** in Settings → Page templates: place checkboxes,
  boxes, and lines, or draw your own — then pick it for any notebook.

## Privacy

Notesy collects no data. See the [privacy policy](PRIVACY.md).
